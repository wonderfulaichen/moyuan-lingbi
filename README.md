# 墨渊灵笔 - AI小说创作工坊

一款基于AI辅助的小说创作工具，帮助作者从灵感萌发到完成整部小说。

## 技术栈

- **前端框架**: React 19 + TypeScript
- **构建工具**: Vite 6
- **样式方案**: Tailwind CSS 4
- **桌面端**: Electron 39
- **状态管理**: React Hooks + localStorage持久化

## 功能模块

| 模块 | 说明 |
|------|------|
| 灵感萌发 | 灵感孵化、方案推荐、标签云、收藏夹 |
| 世界构建 | 管理地点、势力、规则体系、时间线 |
| 角色塑造 | 创建和管理角色，定义性格与关系 |
| 大纲规划 | AI辅助生成小说大纲，章节拆分 |
| 章节细纲 | 将大纲细化为章节规划 |
| 正文创作 | 沉浸式写作编辑器，AI续写、润色、一致性检查 |
| 记忆系统 | 记忆网络图谱（角色/地点/情节关联）、健康检测、版本控制 |
| AI助手 | 全屏聊天界面，任务管理、待办列表、工具调用 |
| 移动端 | 手机版适配，全屏AI助手，底部导航 |
| 成就系统 | 创作者成就体系，写作统计 |
| 番茄钟 | 专注计时器 |
| 白噪音 | 写作背景音 |

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器（浏览器模式）
npm run dev

# 启动Electron开发模式
npm run electron:dev

# 构建生产版本
npm run build

# 打包桌面应用
npm run electron:build-win
```

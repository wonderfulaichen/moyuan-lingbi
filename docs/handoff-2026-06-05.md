## 三、竞品调研结论

### AI 写作工具方向

**InkOS (Narcooo/inkos)** — 当前最值得关注的竞品
- 地址：github.com/Narcooo/inkos
- 开源多 Agent (Multi-Agent) CLI 小说创作系统
- 3 个 Agent 角色：Writer → Auditor → Revisor 闭环流水线
- 核心创新："真相文件" (Truth Files) — 7 套真值状态文件解决长篇幻觉
- 三层交互：全自动管线 / 原子命令 / 自然语言 Agent 模式
- 已实测 45 万字长篇
- 纯 CLI (TypeScript/Node.js)，无 GUI

### AI 编程工具方向（用户说"编程项目也是百万代码"）

| 工具 | 模式 | 与写作的类比 |
|------|------|-------------|
| Claude Code | CLI Agent + 并行 Subagent (200K ctx) | 写作 CLI，一次 hold 整本书 |
| Cursor | GUI IDE + Background Agent | GUI 工作台 + 后台写作 Agent |
| Cline | IDE 插件 + Human-in-the-loop | 每步确认的"手动模式" |
| Copilot Agent | 异步云端 Agent + 自动提 PR | "晚上布置写五章，早上审稿" |

### 产品定位

**核心判断**：墨渊灵笔的优势是 GUI 工作台（可视化、多端覆盖、本地模型），不该转纯 CLI。

**建议路线**：
1. P0：把游离代码（番茄钟/成就/白噪音/记忆体图谱）连入 App
2. P1：AI 助手升级为 Agent 流水线（draft→audit→revise）+ Human-in-the-loop
3. P2：建立"项目真相库"（结构化存储角色/伏笔/世界观）

**不做**：不转纯 CLI，不盲目追功能数量。

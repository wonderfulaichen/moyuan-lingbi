# 统一文件夹系统设计文档

## 设计目标

将内容设定和情节创作的文件夹系统统一，使用相同的 UI 结构和交互模式。

## 当前问题

1. 数据分裂：`project.folders` 中内容设定和情节创作的文件夹各自管理
2. UI 不统一：内容设定用卡片列表，情节创作用特殊视图（OutlineView/DetailedOutlineView/ChaptersView）
3. 回收站分裂：两个独立的 localStorage key
4. 代码重复：StepSettings 和 StepPlot 各自维护文件夹逻辑

## 新设计

### 数据层

`project.folders` 统一包含 6 种预设文件夹：
- `world` - 世界观
- `characters` - 角色
- `timeline` - 时间线
- `outline` - 大纲
- `detailed_outline` - 细纲
- `chapters` - 章节

### UI 层

**内容设定页面**：
- Tab 栏：[世界观] [角色] [时间线]
- 点击 Tab → 进入对应文件夹 → 显示子文件夹卡片 + 文件卡片
- 工具栏：回收站、搜索、多选、视图切换、新建子文件夹

**情节创作页面**：
- Tab 栏：[大纲] [细纲] [章节]
- 点击 Tab → 进入对应文件夹 → 显示子文件夹卡片 + 文件卡片
- 工具栏：回收站、搜索、多选、视图切换、新建子文件夹

**统一回收站**：
- 使用统一的回收站数据存储
- 显示文件来源文件夹
- 恢复时回到原文件夹

### 组件架构

```
UnifiedFolderSystem (通用组件)
├── props:
│   ├── filterTypes: string[]        // 显示的文件夹类型
│   ├── tabLabels: Record<string, string>  // Tab 显示名称
│   └── ...其他通用props
├── 顶部 Tab 栏 (根据 filterTypes 渲染)
├── 面包屑导航
├── 工具栏 (回收站/搜索/多选/视图/新建)
├── 内容区域:
│   ├── 回收站视图
│   ├── 子文件夹卡片网格
│   ├── 文件卡片网格 (网格/树状视图)
│   └── 空状态
└── 右键菜单 / 长按菜单
```

### 文件变更计划

1. **新建** `UnifiedFolderSystem.tsx` - 通用文件夹系统组件
2. **修改** `StepSettings.tsx` - 使用 UnifiedFolderSystem，filterTypes=['world','characters','timeline']
3. **修改** `StepPlot.tsx` - 使用 UnifiedFolderSystem，filterTypes=['outline','detailed_outline','chapters']
4. **删除/废弃** `OutlineView.tsx`, `DetailedOutlineView.tsx`, `ChaptersView.tsx` - 不再使用
5. **修改** `BubbleFolderContent.tsx` - 整合到 UnifiedFolderSystem 或作为其子组件
6. **统一回收站** - 使用统一的 localStorage key 和数据结构

### 后端对接

- `ensureDefaultFolders` 统一创建 6 种文件夹
- `DataService` 的 VFile 系统已经支持任意文件夹类型
- 回收站数据统一存储，记录 `folderType` 字段用于显示来源

### 移动端适配

- 长按菜单（已存在）
- 响应式网格（已存在）
- 触摸友好的按钮尺寸（已存在）
